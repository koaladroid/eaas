# Explainability-as-a-Service (EaaS)

## Thesis Title

Explainability-as-a-Service (EaaS): Operationalizing Explainable AI Through a Service-Oriented Architectural Abstraction

---

## Problem Statement

Explainability techniques such as SHAP and LIME are widely used but remain tightly coupled to model implementations and are rarely deployed as reusable services.

---

## Research Objective

To investigate whether explainability can be operationalized as an independent service capability through a standardized, API-driven architecture.

---

## Research Contribution

This work contributes:

- Explainability service abstraction

- Standardized explanation interfaces

- Model-agnostic explainability orchestration

- API-based explainability operationalization

---

## System Name

Explainability-as-a-Service (EaaS)

---

## Scope

Included:

- FastAPI microservice

- RandomForest and LogisticRegression models

- SHAP and LIME

- Public API deployment

- Standardized explanation schema

Excluded:

- New explainability algorithms

- Explanation quality evaluation

- MLOps platform features

- Enterprise infrastructure

- Frontend applications

---

## Success Criteria

The project is successful if it demonstrates:

1. Explainability can be externalized as a service.

2. Explanation methods can share a common interface.

3. Models can use the same explanation architecture.

4. Explainability can be independently orchestrated.
